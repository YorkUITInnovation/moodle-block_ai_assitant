1. Getting Started
   Upon launching the chat, you'll be greeted by AI the Course Assistant with a message like:
   “Hello, I'm here to help. Ask a question about the course.”
   The chat session begins with a visible timestamp.
2. Typing Questions
   Use the text input field at the bottom of the chat to ask questions related to your course.
   You can inquire about:
   Course content
   Assignment deadlines
   Exam schedules
   Lecture topics
   Any other academic-related queries
3. Using Commands
   Type /help in the input field to view a list of available commands.
   These commands can help you navigate the assistant’s features more efficiently.
4. Sending Messages
   After typing your message, press Enter or click the send icon (if available) to submit your query.
5. Voice Messaging
   If your device supports it, you can send voice messages using the microphone icon next to the input field.
6. Exploring Additional Options
   Look for other icons near the input field to access:
   Settings
   Conversation history
   Reset or clear chat options
7. Accuracy Reminder
   Responses are generated by AI and may not always be perfect.
   Always verify important information with official course resources or instructors.
8. Branding
